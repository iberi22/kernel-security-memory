## Pedagogical Curriculum Modules

### Module 1: Memory Lifecycle & Pointer Nullification
**Vulnerability Archetypes**: Use-After-Free (CWE-416), Double-Free, Asynchronous Callback Lifetime Violations.

#### 1. Empirical Evidence
- **OpenSSH CVE-2023-25136** (`486c4dc3b83b4b81c16fa500845a70656a2bb2f4`): During SSH2 key exchange initialization (`kex_input_kexinit`), fallback compatibility structures retained duplicate pointers to freed packet buffers, permitting pre-authentication UAF.
- **OpenSSH CVE-2021-28041** (`e04fd6dde17c4f420e6c5188f615ef5eb79cc0d0`): `ssh-agent` encountered double-free when processing errors during PKCS#11 provider loading.
- **systemd CVE-2020-1712** (`1068447e6954dc6ce52f099ed174c442cb89ed54`): Asynchronous D-Bus transactions in `systemd-homed` dereferenced freed user context objects when reply handlers executed after parent destruction.
- **systemd CVE-2022-2526** (`d973d94dec349fb676fdd844f6fe2ada3538f27c`): Disconnected TLS streams in `systemd-resolved` failed to scrub back-pointers, causing dangling callback invocations.

#### 2. Causal Invariant Rules for Autonomous Agents
1. **Immediate Nullification**: Every pointer freed via `free()` or `kfree()` must be assigned `NULL` on the very next line if its enclosing scope survives the call.
2. **Asynchronous Lifetime Pairing**: If an asynchronous task or callback is queued with a context pointer `ctx`, the object must maintain an explicit reference count (`refcount_inc`/`refcount_dec`) or registration handle that cancelably unregisters before `ctx` is destroyed.
3. **No Dangling Compatibility Aliases**: Avoid dual references to buffer slices across legacy compatibility wrappers without shared reference counting.

### Module 2: Argument Injection & Subprocess Isolation
**Vulnerability Archetypes**: Command/Argument Injection (CWE-88, CWE-78), Parameter Smuggling.

#### 1. Empirical Evidence
- **OpenSSH CVE-2023-51384** (`881d9c6af9da4257c69c327c4e2f1508b2fa754b`): Destination hostnames and usernames containing shell metacharacters (e.g. `` `cmd` ``, `$(cmd)`) were interpolated into `ProxyCommand` shell expansions.
- **Git CVE-2018-17456** (`1a7fd1fb2998002da6e9ff2ee46e1bdd25ee8404`): Submodule `.gitmodules` URLs starting with `-` (such as `-u/bin/sh`) were passed directly to git subprocess execution, interpreting the URL as a command-line flag rather than an argument.
- **Git CVE-2020-5260** (`9a6bbee8006c24b46a85d29e7b38cfa79e9ab21b`): Embedding raw `\n` or `\r` characters in URLs supplied to git credential helpers allowed protocol injection, leaking credentials for unrelated hosts.
- **Git CVE-2020-11008** (`c44088ecc4b0722636e0a305f9608d3047197282`): Variant permitting protocol injection where empty schemes or missing hosts evaded initial credential sanitizer filters.

#### 2. Causal Invariant Rules for Autonomous Agents
1. **Option Disambiguation (`--`)**: Always inject `--` to terminate option parsing before passing user-controlled parameters to child commands (e.g., `git clone -- "$url" "$dest"`).
2. **Strict Character Allowlist**: Hostnames, usernames, and repository identifiers must strictly match `^[a-zA-Z0-9._-]+$` before passing to shell helpers.
3. **Control Character Rejection**: Reject strings containing `\r`, `\n`, or null bytes before transmitting across line-delimited IPC protocols (credential helpers, daemon commands).

### Module 3: Filesystem Races & Path Resolution Boundary
**Vulnerability Archetypes**: Symlink Traversal, Case-Folding Collisions, TOCTOU Filesystem Desynchronization.

#### 1. Empirical Evidence
- **Git CVE-2024-32002** (`97065761333fd62db1912d81b489db938d8c991d`): A repository containing a symlink directory alongside a submodule path colliding under case-folding filesystems (macOS / Windows NTFS) allowed checking out hooks into `.git/hooks/`, achieving Remote Code Execution upon clone.
- **Git CVE-2021-21300** (`684dd4c2b414bcf648505e74498a608f28de4592`): Delayed clean filter execution during checkout allowed a symlink to be created before a delayed file was written through the symlink.
- **OpenSSH CVE-2018-20685** (`6010c0303ab5306ec711a364be1dc1beec4b455b`): The `scp` client accepted server-specified directory names of `.` or empty string, allowing the remote server to write files directly into the target client directory without namespace prefixing.
- **OpenSSH CVE-2020-12062** (`aad87b88fc753549666ff1237e29ff85a15cfb22`): Malicious scp servers sent duplicate file names in file lists, evading client overwrite confirmation prompts.

#### 2. Causal Invariant Rules for Autonomous Agents
1. **Case-Folded Collision Detection**: Canonicalize paths under case-insensitive comparison (`strcasecmp` / UTF-8 case folding) when operating on cross-platform repositories.
2. **Symlink Boundary Enforcement**: Never follow symlinks when writing files into a sandbox directory. Always use `O_NOFOLLOW` / `lstat` checks.
3. **Strict Target Basename Verification**: Reject remote filenames matching `.`, `..`, empty string, or containing path separators (`/`, `\`).

### Module 4: Protocol State Machines & Logic Boundary Enforcements
**Vulnerability Archetypes**: Desynchronization, Premature Completion, Request Smuggling.

#### 1. Empirical Evidence
- **Nginx CVE-2019-20372** (`c1be55f97211d38b69ac0c2027e6812ab8b1b94e`): When handling an HTTP request with a body where an `error_page` redirect was triggered, nginx redirected the connection without discarding the pending body stream, allowing HTTP request smuggling across upstream connections.
- **Nginx CVE-2017-20005** (`0206ebe76f748bb39d9de4dd4b3fce777fdfdccf`): HTTP/2 frame processing failed to validate header trailer states across stream transitions, leading to corrupt request boundaries.
- **OpenSSH CVE-2025-32728** (`fc86875e6acb36401dfc1dfb6b628a9d1460f367`): State handling during SSH channel window adjustment allowed out-of-sequence channel messages to bypass authentication state.
- **OpenSSH CVE-2023-51385** (`7ef3787c84b6b524501211b11a26c742f829af1a`): Incomplete string parsing during SSH certificate principal checking allowed trailing character mismatches.

#### 2. Causal Invariant Rules for Autonomous Agents
1. **Full Body Drain Invariant**: Before issuing internal redirection or connection reuse, verify and discard any unread request payload stream.
2. **Explicit Finite State Transitions**: Every protocol state machine must explicitly reject unhandled states with strict errors, never silently defaulting to a PASS or CONTINUE state.
3. **Exact String Match for Identities**: Always compare identity tokens using exact length matching rather than prefix matching (`strncmp` with `strlen`).

### Module 5: Resource Accounting & Stack/Buffer Allocation Boundaries
**Vulnerability Archetypes**: Stack Exhaustion (`alloca`), Buffer Sizing Overflows, Infinite Recursion.

#### 1. Empirical Evidence
- **systemd CVE-2021-33910** (`b34a4f0e6729de292cb3b0c03c1d48f246ad896b`): Path escaping function `unit_name_path_escape` allocated memory on the stack via `alloca()` proportional to path length, causing kernel stack overflow on deep paths (>8 MB).
- **systemd CVE-2021-3997** (`5b1cf7a9be37e20133c0208005274ce4a5b5c6a1`): `systemd-tmpfiles` recursively unmounted directory trees without bounding recursion depth, causing process resource starvation.
- **systemd CVE-2022-3821** (`9102c625a673a3246d7e73d8737f3494446bad4e`): `format_timespan` calculated buffer sizes based on time unit multiples without reserving safety margin for the trailing null byte and max integer width.
- **SQLite CVE-2019-19317** (`522ebfa7cee96fb325a22ea3a2464a63485886a8`): Complex subquery expression trees exhausted stack and query memory limits.
- **SQLite CVE-2025-29088** (`56d2fd008b108109f489339f5fd55212bb50afd4`): Window function partition calculations exceeded memory limit controls.

#### 2. Causal Invariant Rules for Autonomous Agents
1. **Ban Dynamic Stack Allocation**: Completely forbid `alloca()` and variable-length arrays (`VLA`) on variable-length user input. Allocate on the heap or enforce hard static caps.
2. **Strict Recursion Caps**: Any recursive traversal (directory trees, expression ASTs, JSON nesting) must pass an explicit depth counter and abort if `depth > MAX_DEPTH` (typically 32 to 64).
3. **Defensive Buffer Sizing**: Buffer allocations for string formatting must compute worst-case bounds (`size = max_units * unit_len + 1`), never optimistic averages.

### Module 6: Query Planner & AST Expression Tree Invariants
**Vulnerability Archetypes**: Bytecode Register OOB, Schema Invalidation Desync, Expression Flattening.

#### 1. Empirical Evidence
- **SQLite CVE-2019-19244** (`e59c562b3f6894f84c715772c4b116d7b5c01348`): Subquery column counts mismatched index layout during query plan flattening.
- **SQLite CVE-2019-19603** (`527cbd4a104cb93bf3994b3dd3619a6299a78b13`): Trigger execution modified schema tables without invalidating active query statement plan caches.
- **SQLite CVE-2019-20218** (`a6c1a71cde082e09750465d5675699062922e387`): Flattening complex nested `SELECT` queries dereferenced unlinked parent AST nodes.
- **SQLite CVE-2026-39113** (`169f68ed88b34cb68f720191c64c058f2ccec508`): Generated virtual machine bytecode omitted upper-bound register checks.
- **SQLite CVE-2026-50812** (`b869ed6b067d623cb1383549f2a18aa35508385d`): Parser AST depth token validation failure under deeply nested compound select queries.
- **SQLite CVE-2026-50813** (`c597ed79d1bd03f57198d10d1f431adda293cf2e`): Aggregate window function state failed to reset accumulator state across partition boundaries.

#### 2. Causal Invariant Rules for Autonomous Agents
1. **Schema Cache Invalidation**: Any structural mutation (schema change, trigger, table alter) must immediately invalidate all prepared statements and cached execution plans.
2. **Bytecode Register Verification**: Every register access in a generated VM or bytecode stream must be validated against allocated register file bounds prior to execution.
3. **AST Node Ownership**: Expression tree transformations must strictly preserve parent-child link invariants and null-check flattened intermediate nodes.

### Module 7: Concurrency Windows, Timing Side-Channels & Privilege Gates
**Vulnerability Archetypes**: TOCTOU Concurrency, Side-Channel Timing Leaks, Authorization Bypass.

#### 1. Empirical Evidence
- **systemd CVE-2022-45873** (`076b807be472630692c5348c60d0c2b7b28ad437`): Journal reader stream dropped lock temporarily while rotating buffers, creating a race condition window where incoming logs corrupted stream position.
- **OpenSSH CVE-2023-51767** (`8241b9c0529228b4b86d88b1a6076fb9f97e4a99`): PAM authentication checked nonexistent users faster than existent users, exposing a side-channel timing discrepancy that permitted user enumeration.
- **systemd CVE-2022-4415** (`b7641425659243c09473cd8fb3aef2c0d4a3eb9c`): `systemd-coredump` failed to verify caller UID permissions before generating crash dumps containing sensitive process memory.
- **systemd CVE-2026-29111** (`1d22f706bd04f45f8422e17fbde3f56ece17758a`): Polkit authorization token verification failed to check issuer signature prior to executing privileged actions.

#### 2. Causal Invariant Rules for Autonomous Agents
1. **No Concurrency Windows**: Do not drop and re-acquire locks across a single logical state update. Maintain critical section invariants from initial check through completion.
2. **Constant-Time Verification**: Security credential checks (passwords, HMACs, token verifications) must execute in constant time regardless of whether the user exists or where the mismatch occurs.
3. **Fail-Closed Privilege Gating**: Always verify caller credentials (`getuid()`, polkit token) before accessing privileged process state or core dumps.
